# Phase 2 — YAML & JSON Challenges

Real-world practice with the two data formats you'll touch every single day in DevOps.

## Challenges

| # | Folder | What you do |
|---|--------|-------------|
| 15 | `jq-workout/` | Slice and dice real API JSON with `jq` |
| 16 | `k8s-manifests/` | Write Kubernetes-style YAML by hand |
| 17 | `yaml-validator/` | Deliberately break YAML and diagnose the errors |
| 18 | `github-actions-pipeline/` | Write a real GitHub Actions workflow from scratch |

## Skills covered

- YAML syntax quirks — indentation, lists vs maps, multi-line strings, anchors/references
- JSON querying and transformation with `jq`
- Mental validation of YAML files
- How real CI/CD pipelines are structured

## How to start

Start with `15-jq-workout/` — it takes 30 minutes and gives you a tool you'll use forever.
Then do `16-k8s-manifests/` and `17-yaml-validator/` in any order.
Finish with `18-github-actions-pipeline/` which ties everything together.
