# Extra Challenges

This folder holds additional challenges I took on after the review meetings,
beyond the original ten in the roadmap. They came out of topics and questions
that were discussed in the review sessions, so I implemented them hands-on to
solidify the concepts.

## Challenges

- **nginx-routing** — Running several services on the same host with nginx in
  front as a reverse proxy, routing traffic to each service by request path.

Each challenge has its own folder with the code, configs, and a README
explaining what I did and why.
