# 06 — CI/CD

Phase 3 CI/CD challenges. Each challenge is self-contained with its own README.

## Challenges

- `pipeline-stages/` — Challenge 27: lint → test → build → deploy, and why that order matters
- `triggers/` — Challenge 28: push, PR, schedule, and manual triggers
- `secrets-in-ci/` — Challenge 29: secrets management — never hardcoding credentials
- `artifact-management/` — Challenge 30: build once, promote the same artifact through environments
- `pipeline-caching/` — Challenge 31: speeding up pipelines by caching dependencies
- `full-deploy-pipeline/` — Challenge 32: tests on every PR, auto-deploy on merge to main
