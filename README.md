\# Intern Challenges — Networking Basics \& Version Control



Hands-on, implementation-based challenges completed as part of my DevOps

internship. Each challenge is implemented using Docker containers on custom

networks, and every subfolder has its own README explaining the task, the

steps I took, and what I observed.
