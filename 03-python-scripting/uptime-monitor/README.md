# Challenge 11 — Website Uptime Monitor

## Scenario

> *"Our team kept finding out the company staging site was down only when a customer complained.
> Your first task: write a script that pings it every N minutes and sends an email alert the moment it goes down."*

This is one of the most common first-automation tasks given to DevOps interns. You'll touch
`requests`, error handling, environment variables, and `subprocess` — all in one short script.

---

## What you will build

A Python CLI script `monitor.py` that:

1. Accepts a URL and an interval (seconds) as arguments
2. Makes an HTTP GET request to the URL
3. If the response code is **not** 2xx, or the request **times out / errors**, it triggers an alert
4. The alert is sent as an email via `smtplib` (or as a fallback, just prints + writes to a log file)
5. Loops forever, sleeping `interval` seconds between checks

## Functional requirements

### 1. CLI arguments
Use `argparse` — no hardcoded URLs.

```bash
python monitor.py --url https://example.com --interval 60
```

### 2. The check function

```python
def check_url(url: str) -> tuple[bool, str]:
    """
    Returns (is_up, reason).
    is_up=True  → site responded with 2xx
    is_up=False → any other outcome, with a human-readable reason
    """
    ...
```

Requirements:
- Use a **timeout** on the request (5 s is reasonable)
- Catch `requests.exceptions.ConnectionError`, `requests.exceptions.Timeout`, and any other `RequestException`
- Return `False` + a descriptive reason string for every failure mode

### 3. Alerting

At minimum, write a function `send_alert(url, reason)` that:
- Prints a timestamped message to stdout
- Appends the same message to `monitor.log`

**Stretch goal**: actually send an email using Python's built-in `smtplib`.
Use Gmail SMTP (port 587, STARTTLS). Read credentials from environment variables — **never** hardcode them.

```python
import os, smtplib
SMTP_USER = os.environ["SMTP_USER"]
SMTP_PASS = os.environ["SMTP_PASS"]
ALERT_TO  = os.environ["ALERT_TO"]
```

### 4. Main loop

```python
import time

while True:
    is_up, reason = check_url(args.url)
    if not is_up:
        send_alert(args.url, reason)
    time.sleep(args.interval)
```
