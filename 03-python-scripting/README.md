# Phase 2 — Python Scripting Challenges

Real-world automation scripts you'd actually write on the job as a DevOps intern.
Each challenge is self-contained inside its own folder with a detailed `README.md`.

## Challenges

| # | Folder | What you build |
|---|--------|----------------|
| 11 | `uptime-monitor/` | Website uptime checker that emails you on failure |
| 12 | `log-parser/` | Parse Nginx access logs and surface top errors & IPs |
| 13 | `api-health/` | Hit a real REST API, parse the JSON, alert on bad state |
| 14 | `deploy-notifier/` | Run a shell command from Python and report its outcome |

## Skills covered

- Core syntax, data structures (lists, dicts, sets), functions, `try/except`
- `requests` library, JSON parsing, auth tokens
- `os`, `subprocess`, `pathlib`
- Real automation scripts that solve a real problem
- `venv` and `pip` basics

## How to start

Each folder has its own `README.md`. Work through them top-to-bottom — each one
builds on patterns introduced by the previous challenge.
